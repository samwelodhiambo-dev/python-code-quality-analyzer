Python Code Quality Analyzer

A lightweight Python static analysis tool designed to identify common coding issues and improve code quality.

Features

- Python syntax error detection.
- Function naming convention checks.
- Missing function docstring detection.
- Bare exception handling detection.
- Automated unit tests.
- Clear code quality reports.

Technologies

- Python 3
- Abstract Syntax Trees (AST)
- pathlib
- unittest

Project Structure

Installation

Clone the repository:

git clone https://github.com/samwelodhiambo-dev/python-code-quality-analyzer.git

Navigate into the project:

cd python-code-quality-analyzer

Running the Analyzer

python main.py

Running Tests

python -m unittest -v

Purpose

This project demonstrates Python programming, static code analysis, automated testing, debugging, and software quality assurance.
